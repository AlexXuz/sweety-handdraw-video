# 主题手绘视频

交付可播放成片、封面、字幕、口播稿和检查记录。默认简体中文、1920×1080、30fps；用户的语言、尺寸、画风、声音和复用要求优先。片长随内容和实际配音变化，不固定页数、布局或每页秒数。

## 开工

先读[依赖路由](references/dependencies.md)，再按需读取内置指南。它们是本技能的制作资料，不另行安装，也不自行接管任务。主体内容由模型推理设计，脚本只执行已确定的素材与时间线。

1. **讲清因果。** 确定受众、要解决的问题、机制、必要反例与行动。改编文章先读全文并保留限定、署名与来源；时效或有争议事实核实一手资料。默认评估“生活常见错误→概念→机制→行动→收束”是否适用；用户指定优先，不适用时用内置导演方法规划。判断写入 `design.json`，详见[创作与分镜](references/story-design.md)。
2. **配音先行。** 通过 VoiceStudio 生成并核对逐段音频，或复用用户认可的导出文件，再测量时长。默认 Iapetus 合成参考音色，五款可选；不要求用户逐次重选。缺少 VoiceStudio 时不能生成新旁白，不自动换供应商，也不把无声片当成成片。接口和编辑方式见[声音与依赖](references/local-runtime.md)。
3. **设计可绘制的图。** 每张生成图、候选、编辑、封面与新手部素材都必须先应用内置美术指导，保留手绘风格完整配方，写简报和提示词。先做代表画面，核对主体、接触、构图和部位可分性，再扩展同片素材。新主题重新设计；本片修订或用户明确复用时保留已通过的图和声音。封面主视觉可由 AI 生成，准确文字用可编辑图层合成。所有生成图执行内置隐私清理，删除其模拟相机字段，再查元数据和来源属性。
4. **按实际图像分部位。** 通常依次为头、颈、躯干、画面左臂、右臂、下半身及道具；特殊构图解释例外。模型看图标注语义区域，处理遮挡，不能按矩形把人物草率切碎。整幅图先完成全部轮廓，再按同一顺序填色。笔画独立，笔间抬笔；颜色仅在笔刷经过范围出现。每个字形隔离，前字未完成不得露出后字；按真实字形边界留边，检查字脚、标点和拉丁字母下伸部。
5. **编排和代表段检查。** 按[运行格式](references/runtime-contract.md)写任务。画面围绕完整意思逐步累积，复杂度须适合真实语音时长。固定封面1秒：前0.5秒静止，后0.5秒渐隐，再开始正文和旁白。先渲染覆盖文字、插画、上色、字幕与转场的代表段，检查笔尖、手臂、遮挡、阅读停留和声画对应，再渲染整片。
6. **核对后交付。** 按[质量检查](references/quality-gates.md)检查最终文件。工程、画面、动作、内容与声音证据分别记录，发现失败修正对应层后重渲染。未实际听音就明确主观听感未验收；不把解码、ASR、文件存在或规则加载说成观感保证。`finalize`只接受匹配当前视频的检查记录。

## 手部和广告

默认 `navy` 深蓝袖马克笔；另有 `diamond-woman` 白皙柔粉碎钻长甲、`child-pencil` 儿童彩铅、`waner-brush` 上官婉儿灵感毛笔、`teacher-pen` 白衬衫中性笔、`cardigan-fountain` 针织袖钢笔。锚点在 `assets/hands/catalog.json`。按笔尖到手腕校准显示尺度，前臂裁切边始终在画外。

`hand.pen_text` 添加笔杆文字，默认空；保持用户提供的文字，正常尺寸检查对比度和可读性。过长难读时优先扩大可用笔杆排版或简化设计，不擅自修改广告名称。自定义皮肤、美甲、笔具与袖子须走同一美术、隐私及锚点检查。碎钻不替换为大颗宝石，清晰皮肤不以模糊换取。

## 运行与边界

`scripts/handdraw_video.py` 提供 `doctor / build / render / verify / finalize`。先读运行格式再调用；任务数据放独立目录，不写入安装目录。`doctor`区分新旁白生成服务与已有音频的离线合成条件。缺少必要资料或能力时报告具体阻碍。

质量优先。工程门槛验证执行顺序和完整性，模型仍要审查语义分区与设计。汉字为字形近似描线，不保证书法笔顺；真实手写自然度、情感和学习效果须分别评价。不承诺任意主题都能一次稳定生成。不额外发布视频、开通服务或改变全局模型配置。
