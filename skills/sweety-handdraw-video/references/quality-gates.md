# 检查与返工

工程检查与观感检查分别记录。`verify` 输出工程结果，并生成实际 MP4 的抽帧；`finalize` 仅在工程结果匹配当前文件且人工/模型检查记录明确通过时生成交付回执。

## 工程检查

- 缺少模型叙事路线判断、美术指导依赖、提示词/简报、图片通过记录或匹配哈希时拒绝生产；图集仅允许已审过的裁切。
- 每个插画像素都有语义部位归属，所有轮廓结束后才填色，两个阶段均按同一部位顺序；字符按各自起止窗口隔离；实际字形四边须保留空白，不能裁掉字脚或下伸部。笔划间抬笔移位。
- 前臂裁切边位于画布外；封面0.0—0.5秒静止，0.5—1.0秒按实际像素渐隐，1秒后才开始旁白。

- 完整解码音视频，核对分辨率、帧率、编码、音画时长差和响度。
- 每条字幕对应实际语音段，时序有序，无越界；检查最后一句没有被截断。
- 正文元素都在画布内、使用绘制路径，同一主笔事件不重叠；主体绘制结束后有短暂停留。
- 文字和线稿的显现位置靠近笔尖；每个颜色像素的出现都有真实笔刷覆盖，不允许剩余色块在最后一帧整体补齐。
- 单独检查小面积色块、无彩色填充图、短标点、粗笔画端点、长标题和不同页面数量。不要通过放松断言掩盖路径缺失。
- 图像清理后的元数据与来源属性分别报告，不把隐私处理当作 AI 检测保证。

## 观感与内容检查

查看最终导出文件：全部页面完成图，代表性绘制过程，字幕换行与转场、封面首尾。使用可用播放器检查连续播放；有听音工具时实际听音，没有时用ASR与音轨检查并明确听感未验收。

记录 `review.json`：

```json
{
  "video_sha256": "实际视频哈希",
  "content": {"status": "pass", "evidence": "事实/限定/来源和字幕已核对"},
  "visual": {"status": "pass", "evidence": "实际看过的帧、时间段及修正结果"},
  "motion": {"status": "pass", "evidence": "实际看过的绘制/上色/转场；说明播放器或连续帧方式"},
  "audio": {"status": "pass", "evidence": "ASR或听音依据，说明最终音轨是否重核"},
  "privacy": {"status": "pass", "evidence": "清理工具、复核结果和残留边界"},
  "limitations": ["未实际完成的听感或其他主观验收"]
}
```

`pass`、`fail`、`not_checked` 必须基于观察，不可由脚本自动填成通过。若只检查了ASR，不能写“已经完整听过”。模型查看抽帧可以验证字形和版面，不能单独证明全片运动流畅。

## 返工规则

先定位问题属于内容、素材、声音、路径还是时间安排；只改对应层。比如字符短笔画跳出，修字形路径；笔触太快，简化画面或增加合理分段；AI图集串入邻图，修裁切或重新生成；读错词，重做该语音段并重算下游时间线。

同一失败连续三次没有改善时改路线或报告具体阻碍。不要无限生成付费素材、把相同失败当新候选，或仅延长视频掩盖机制问题。交付记录保留最终通过证据与仍然未验收的边界。

## 导演终审和声音边界

按随包 omniailab `FILM-ART` 检查每页是否服务讲解、重点是否明确、动作与语音是否冲突、收束是否回应开头。记录实际看到的不足和修正，不能只写“已加载导演 Skill”。艺术动效命中 huashu 时再启用其类型方法，并保留本流程的硬性要求。

五款声音的文件存在、合成成功和 ASR 正确只能证明可用性与文字识别情况；“咬字自然、有情感、适合讲课”需要实际听音判断。无可用听音工具时将 audio 证据写成“文字/音轨检查通过，主观听感未验收”，并在 limitations 和交付说明明确保留这一点。不得自动填写“声音很好”。

代表性连续帧能发现分部位顺序、漏出、突然补色和手臂断边，但稀疏抽帧不能证明逐帧流畅。至少检查所有页面的绘制阶段；有可用播放器时播放完整成片。保留检查范围，不把一条片通过扩展为任意输入都稳定。

部位审查还要检查遮挡：发丝间露出的伞面属于伞，手持物不属于手臂，包与腿相交处按实际前后关系分配。程序只能验证给定归属的执行顺序，不能证明模型分区语义正确。剩余区域只能收纳明确的雨线、地面等辅助元素，不能吞掉头部、手臂或道具主体。
